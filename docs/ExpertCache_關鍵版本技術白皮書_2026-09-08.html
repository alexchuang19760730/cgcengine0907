🎯 關鍵實驗結論（2026-09-08）

1. IQ3_XXS 抖動根因：不是 expert cache，是 logits 邊界 + GPU 浮點

配置確定性（15+27 × 6-10）速度結論
全 exact（VERIFY=0 DRAFT=0）42×13 / 22×2（仍 13% 抖）6.3 t/s ❌ZERO-slot 不是根因
8GB 預設 guard 0.3042×9 / 22×1（90%）28 t/s甜蜜點
10GB 無 RN42×9 / 22×1（90%）28 t/s加大 pool 無額外收益
4GB / 6GB60% / 50% ❌—LRU churn 更糟
10GB + RN_ROUTING全同但全錯（echo）21-22 t/srenorm 改選擇 → 確定地錯

機制：「42」與「22」的開頭 token logits 差距極小（±1e-4 級），Metal parallel reduction 順序受並發負載影響 → 邊界 token 偶爾翻轉。expert cache 只是放大器之一，不是必要條件。

2. Q4_K_M 檔（23GB）在 16GB 上不可用

配置結果根因
Q4_K_M ngl=99234 個 buffer nil + OOM 掛掉experts 實際是 Q6_K（非 Q4_K），23GB 檔超出 16GB 載入能力，adoption 全失敗
Q4_K_M ngl=30CPU crashexpert cache partial-offload 契約未修（既有問題）
IQ3_XXS-denseIQ4X（現行）90% 確定 + 28 t/s + 質量 1.0experts IQ4_XS = expert cache 設計目標格式

⚙️ 關鍵環境變數參數

核心開關（生產 ON）

CGC_VERIFY_DECODE / CGC_DRAFT_DECODE — ZERO-slot fast path（phase 判別後 verify/draft 專用）
預設：ON | 關掉 = 全 exact = 6.3 t/s（確定但太慢）

CGC_FAST_COLD_MAX — verify cold guard 門檻（冷比例超標走 exact）
預設：0.30 | 0.0 = guard 停用（ZERO 全開，勿設）

CGC_DRAFT_STRICT — draft 有 1 個冷 expert 即 exact
預設：ON | draft 每步只有 8 個 expert，fill 成本極小

CGC_LOOP_GUARD — server-side phrase-loop guard
預設：ON | 相同 ≥6 字元片語連續 ≥3 次截斷

Pool 配置

CGC_SERVER_EXPERT_CACHE_BYTES — expert cache pool 大小
預設：8GiB (8589934592) | 16GB 機甜蜜點；4/6GB 品質崩、10GB 無額外收益

CGC_SERVER_CTX — context 長度
預設：8192（Claude Code CLI 最低 3117 tokens）

LLAMA_EXPERT_CACHE_L4_SKIP_LAYER0 — layer 0 排除 L4 pool
預設：ON | layer-0 保留完整權重避免污染

實驗參數（預設 OFF，勿在生產開啟）

CGC_RN_ROUTING — router softmax 前 mask 冷 expert 至 -inf
預設：OFF | 已驗證死路：改選擇 → 確定地錯（質量 0.3）

CGC_WCOLD_EN — weighted cold ratio guard
預設：OFF | logits callback 未穩定觸發，count-based 較可靠

CGC_DBUF / CGC_DBUF2 — step-ahead refill / 雙緩衝
預設：OFF | DBUF spike 曾達 24.83 t/s，但 16GB 上 DBUF2 降速 40%

CGC_FAST_WAIT — 等待 in-flight fill 而非 ZERO-map
預設：OFF | 只對「已在載入」的 expert 有效，冷啟動無效

CGC_PREV_TOKEN_PREFETCH — prev-token prefetch
預設：OFF

CGC_SPAC / CGC_SPAC_ALPHA — SpAc EMA estimator
預設：OFF / α=0.75（v1.0.0 前曾為 25.17 t/s 的配置）

採樣參數（質量防護）

--temp — 0.4（降低首 token 噪聲）

--top-k — 0（禁用），用 min-p 動態閾值替代

--top-p — 0.8（no-think 官方推薦）

--dry-multiplier / --dry-allowed-length — 1.0 / 10（DRY 防迴圈）

presence_penalty — 1.5（replay harness 全部 prompt）：pp=0 開頭 echo `thinking\nresponse`，pp=1.5 正常開頭
