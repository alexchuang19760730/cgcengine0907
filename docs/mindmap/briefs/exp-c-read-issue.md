## 1. 目標

⚠ 本節點**不是新門**：`io-shape`（tier 4）已經量過同一件事並判死——「合併邏輯早已存在 （preadv）；**固定開銷占 90%**」，且一個 expert 的三段相隔 88–115 MB ⇒ 3→1 要付 182.6× 位元組， 收益 ~2.9% < 3% 門檻 ⇒ 不值得 rebuild（docs/IO_AXIS_VERDICT_2026-09-25.md）。 本節點的**唯一**工作是：用 2026-09-28 E-A 的新鮮讀數（0.37 MiB/job、us/job=1856、jobs=24912、 fill_wait_us 僅 0.101 s／47.9 s）去**重驗那個判決**，而不是假裝沒看過它。 要回答的判別問題：E-A 的「讀取總時 46.2 s」與「臨界路徑只等 0.101 s」這兩件事是否**同時成立**、 以及若成立，是不是正好解釋了 io-shape 的 2.9%？ 預期的正面結果是**確認** io-shape，而不是推翻它。

## 2. 判準

重驗完成且**回填 io-shape**：E-A 的 47.9 s／0.101 s 兩數同時成立 ⇒ io-shape 的 2.9% 判決維持，本節點結案（tier 4，不新增槓桿）

## 3. 結果

**已由同題判詞結清**：`io-shape`（已結）量過同一問題——收益 **2.9% < 3%** 門檻 ⇒ 判為背景。卡在（targets 14.0），**不再獨立跑**。

## 4. 判定

**3a · ③a 實驗目標達成（階段性）** — 達成實驗設計目的（機制／量測成立），但產物還不能放進生產級設置
