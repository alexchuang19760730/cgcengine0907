⑤ 哪些槓桿最有希望把 server 拉到 30+

從 latest 的 69.08 ms/token 拉到 33.33 ms/token，總共要再砍 35.75 ms/token。按現在證據，最有希望的不是平均撒網，而是按優先順序一刀一刀吃。

槓桿預估收益依據備註
先把 longform benchmark 線回到 legacy-25plus profile -31.06 ms/token 已實測：26.31 t/s vs 14.48 t/s 這一刀本身就能把 longform 從 14.5 拉回 26.3。
在 legacy-25plus 線上重 sweep n_max=2/3、batch/ubatch -2.0 ~ -2.5 當前 old-good 已經健康，適合做純性能 sweep 這一刀比在 latest 壞線上 sweep 更乾淨。
把 semantic debug / extra prompt logging 完全移出 benchmark 線 -0.5 ~ -1.0 屬熱路徑外衣，應避免帶進 production benchmark 不是主因，但應該順手拿掉。
再把 longform accept 從 97% 往 99% 推 -1.0 ~ -1.5 目前 server old-good 已接近，仍有小幅空間 偏細修，但足以吃掉最後幾 ms。
wrapper / JSON / HTTP 微優化 -0.3 ~ -0.7 本次分解已證明它不是主槓桿 可以做，但順序應排後面。

也就是說，現在要到 30+ 的最短路，不是繼續在 latest 壞線上找零碎優化，而是：

  • 先讓 longform benchmark 固定走 legacy-25plus 這條健康線；
  • 再在這條線上做 n_max / batch / ubatch 的純性能 sweep；
  • 把 QA-only native-thinking contract debug 留在另一條隔離線，不要再共享 longform benchmark。

⑦ Windows 端如何連上我們的 server

目前 server 已經提供 OpenAI-compatible 介面。Windows 端不需要懂 llama.cpp 內部細節，只要把 Base URL 指到 Mac 上的 /v1 就可以。

項目說明
Base URLhttp://<Mac LAN IP>:8080/v1 或你實際啟動時指定的 port，例如 http://192.168.101.87:8099/v1
Chat CompletionsPOST /chat/completions
ModelsGET /models
Auth目前本地 LAN 測試線不需要 API Key；若上外網再另外補保護。
# 先在 Mac 上啟動 server
CGC_SERVER_MODEL_ROOT=/Users/alexchuang/Documents/flashkv0516/models/gguf \
CGC_SERVER_PROFILE=legacy-25plus \
CGC_SERVER_PORT=8080 \
bash scripts/run_server.sh

# Windows PowerShell 測試：列出模型
Invoke-RestMethod -Method Get `
  -Uri "http://192.168.101.87:8080/v1/models"

# Windows PowerShell 測試：chat.completions
$body = @{
  model = "test"
  messages = @(
    @{ role = "user"; content = "請用一段中文說明巴黎為什麼是法國的政治與文化中心，避免條列，至少120字。" }
  )
  temperature = 0
  max_tokens = 220
  stop = @("<|end|>", "<|output|>", "<|user|>")
} | ConvertTo-Json -Depth 6

Invoke-RestMethod -Method Post `
  -Uri "http://192.168.101.87:8080/v1/chat/completions" `
  -ContentType "application/json" `
  -Body $body
  • 若 Windows 端連不上，先檢查 Mac 的防火牆是否允許該 port，並確認兩台機器在同一個 LAN。
  • Mac 本機自測 localhost 時要加 --noproxy '*'；Windows 對 LAN IP 通常不需要。
  • 若要給第三方 SDK（OpenAI SDK、LangChain、LobeChat 等）接，只要把 base URL 改成這個 /v1 即可。
