⇒ **引擎自己就想降 n_gpu_layers 來塞進可用 device 記憶體，是被 profile 釘死的 ngl=99 擋下來的。**

### (d) ★ 這題真正的軸是 `-ngl`，不是 mmap/none —— 而且是樹裡從沒量過的軸
- `scripts/run_server.sh:488 NGL_DEFAULT=99`（全卸載）；`:530` 的 `CGC_SERVER_OOM_SAFE=1`
  ＋ `PHYS_MEM_GB<=16` ⇒ **ngl=8 / ctx 1024 / batch 64 / ubatch 32 / BUDGET=0**。
  ⇒ 「16 GB 安全形狀」樹裡早就有了，**但從沒量過速度**。
- repo 有 `Backup/cgc_logs/ub_ladder`（寬度軸量過），**沒有任何 ngl ladder**。
- `common_fit_params` 那段警告 = 直接證據：把 ngl 交給 fit（或不釘 99）才是這台機器的槓桿。
⇒ 二選一是假命題：**mmap/none 是 host 頁屬性，撞的牆是 GPU 工作集；而 GPU 工作集的第一槓桿是 ngl。**

### (e) 方法論：盒況單調惡化，interleave 只平衡順序、不平衡水位
r1_none 起跑 swap=3235 MiB → r1_mmap 起跑 swap=**6526 MiB**（swap total 4096→8192 自己長大）。
⇒ 「對照臂存活 ⇒ 盒子 OK」這條規則有洞：盒子在**單調變髒**，R2 兩臂都會更髒。
建議：判準條件化在 before-swap（兩臂水位差 >50% 就標 confounded），
或乾脆等乾淨窗。**警告本身是 box-independent 的**（device 屬性 vs allocated size），
存活則是 box-dependent ⇒ 兩者要分開引用。

### (f) 凍結判準還缺一條：存活 ≠ 贏
對照臂今晚 req = 243.99 / 258.25 / 253.2。mmap 若「存活但 req2 慢一半」或「只 req1 活」，
都不該算設計勝利 ⇒ 應凍結 `survived=yes 且 req2/req3 ≥ 250`。

### §EN- 2026-09-26 11:28（`n_main` 是什麼 —— 定義）

**`n_main`（`ggml-metal-context.m:1141`）＝ Metal 後端把一張圖切給「誰來編碼」的那條分界線。**
- 每次 `ggml_metal_graph_compute` 要開 **`n_cb + 1`** 個 command buffer。
  **slot `n_cb`（最後一個）由呼叫執行緒（主執行緒）自己序列編碼並提交**，涵蓋節點
  `[0, n_nodes_0)`；其餘 **`n_cb` 個 buffer 由 worker 執行緒並行編碼**，各吃剩下的 `1/n_cb`
  （代碼原文 `:592-593`）。`n_nodes_0 = MIN(n_main, N)`（`:1172`）。
- **設計意圖**：主執行緒先提交一批 ⇒ **GPU 立刻有活幹**；然後才啟動 worker 編剩下的。
  所以它是一個權衡：`n_main` 大 ⇒ 提交晚但 GPU 前置活厚；小 ⇒ 提交早但 worker 可能餵不上。
- **為什麼這裡的 64 特別重要**：`n_main = MAX(64, 0.1 × N)`。**每段呼叫一次 `graph_compute`**，
  而 CGC fork 把 trunk 切 ~41 段 ⇒ `N ≈ 99` ⇒ `0.1×99 = 9.9` ⇒ **`MAX(64, 9.9) = 64`**
  ⇒ **65% 的節點歸主執行緒，8 個 worker 只分 ~35 個。**
  ⚠ 上游那個 **64 是在 M1 Pro／M2 Ultra ＋ LLaMA 上「empirically determined」**的（`:1130`）；
  長圖（4076 節點）才輪到 `0.1×N` 說話，**而分段把它變成小圖 ⇒ 地板接管**。
- ⚠ **它會改變 command buffer 的切法 ⇒ 改變 GPU 上的執行切片。** 數值**應該**不變
  （每個節點的值逐節點決定），**但這是必須被證明的斷言** ⇒ 若落地成預設，**必須先過 D5
  （同 build 對照臂，(c) 方案）**。
- **實測（(甲) sweep）**：`pp` 對它明顯敏感（`nm16` −17.8% vs 控制臂），
  `tg` 非單調（16→+3.1%、32→+35.2%、128→+16.2%）⇒ **不背書，待緊湊 ABBA**。
